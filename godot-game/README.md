# Genre Mix Game · This is ME Project

Godot 4.7.2 기반의 2D 장르 믹스 게임입니다.

초기 흐름:

1. Card
2. Platform
3. Rhythm
4. Roguelike
5. Shooter
6. Final Boss

## 현재 구현

- 하나의 긴 횡스크롤 복도에 6개 장르 방 배치
- 조커 뽑기 카드 게임
- 코인 3개와 아이템이 있는 플랫포머
- 치이카와 모양 경로를 완성하는 리듬 게임
- 화염·번개·얼음 4단계 강화 로그라이크
- 솔로/LAN 대전을 지원하는 3D FPS
- 다섯 장르를 연속으로 사용하는 다단계 최종 보스전
- 사용자 사진 기반 주인공과 동아리장 보스 캐릭터
- `A`/`D` 또는 방향키로 캐릭터 이동
- 방 앞에서 `E`를 눌러 입장
- `ESC`로 일시정지 및 설정 메뉴 열기
- 설정 메뉴에서 BGM/효과음 볼륨 조절 및 게임 종료
- 현재 방을 클리어하면 다음 구역 잠금 해제
- `F11`로 전체 화면/창 모드 전환
- 개발 중에는 숫자 `1`~`6`으로 원하는 방에 바로 입장
- 보스전에서는 `F3`으로 현재 챕터 건너뛰기

## 실행

`project.godot`을 Godot 4.7.2에서 연 뒤 `F6` 또는 우측 상단 실행 버튼을 누릅니다.

## Windows 배포

1. Godot에서 `프로젝트 > 내보내기`를 엽니다.
2. 내보내기 템플릿이 없다면 Godot가 안내하는 템플릿을 설치합니다.
3. `Windows Desktop` 프리셋을 선택하고 프로젝트 내보내기를 누릅니다.
4. 결과물은 프로젝트 상위의 `build/GenreMixGame.exe`에 생성됩니다.

효과음 라이선스 정보는 `assets/audio/sfx/SFX_LICENSE.md`에 정리되어 있습니다.
