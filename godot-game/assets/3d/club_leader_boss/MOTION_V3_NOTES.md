# 보스 모션·헤어·의상 v3 제작 기록

게임은 `club_leader_boss_motion_v3.glb`를 사용한다. Blender 원본은 프로젝트 루트 `blender_project/club_leader_boss/club_leader_boss_motion_v3.blend`, 제작 코드는 `blender_tools/refine_boss_motion_v3.py`다. 이 코드는 보존된 rebuilt_v2.blend를 읽으며 v2 원본과 이전 모델은 보존한다.

## 모션
원래 인체 골격과 이름을 보존하고, 보조 골격을 단순 회전하는 대신 실제 어깨→팔꿈치→손목, 엉덩이→무릎→발목 길이를 이용해 두 관절 IK로 자세를 맞췄다. 발 지지/들기 구간, 반대쪽 팔 스윙, 몸통의 무게 이동, 편 손목과 손가락의 가벼운 굽힘을 키프레임으로 베이크했다. 외부 모션 캡처 자료를 사용하거나 상용 게임의 동작을 복제하지 않았다.

GLB에 포함된 6개 클립: `Boss_Idle`(2초), `Boss_Walk`(약0.9초), `Boss_StrafeLeft`/`Boss_StrafeRight`(약0.9초), `Boss_Cast`(약0.85초), `Boss_Dash`(1초). Godot AnimationPlayer가 대기/걷기/좌우 이동을 0.18초 블렌딩하고 시전/돌진은 0.12초 블렌딩한다. 이동량에 맞춰 재생 속도를 조정하고 뒤로 이동할 때는 걷기를 역재생한다. 일반 이동 속도는 2.8m/s로 제한하고 회전은 보간한다. 전투 효과음·범위·피해 규칙은 유지한다. 사망 시 AnimationPlayer를 멈추고 기존 바닥 맞춤 쓰러짐으로 전환한다. ESC 일시정지와 퇴장 시 정리도 적용한다.

## 외형
- 외투 앞판을 열고 안쪽 면 티셔츠를 별도 메시로 넣었다. 옷 여유·두께·배/팔꿈치 주름을 추가하고 양쪽 지퍼, 접힌 옷깃, 포켓, 목 시보리를 분리했다.
- 바지에도 여유와 무릎 주름을 추가했다. 의상은 같은 골격으로 변형되는 별도 메시이며 실시간 천 물리 시뮬레이션은 아니다.
- 기존 헤어 속 볼륨을 유지하며 정수리·옆·뒷머리에 닫힌 단면의 입체 머리 묶음을 추가했다. 머리 골격을 따라 움직이며 가닥별 물리 시뮬레이션은 없다.
- 얼굴 텍스처는 v2의 사진 참고 UV 아틀라스를 유지했다. 턱선과 턱의 돌출을 소폭 조정했으며 사진의 인상은 보존한다.

이번 단계에서 새로운 imagegen 이미지는 만들지 않았다. 기존 얼굴 이미지의 생성 방식·최종 프롬프트는 `REBUILT_ASSET_NOTES.md`를 참고한다. 신규 의상/헤어/동작은 Blender 메시·재질·골격 키프레임으로 작성했다. 상용 AAA 게임과 같은 수준의 조형/리깅/모션 품질을 보장하는 결과로 취급하지 않는다.
